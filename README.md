# MagicData IntelliSense for VS Code

An official VS Code extension providing AutoComplete and real-time documentation for the **MagicData** language.

## Features

* **Element Completion:** Typing `<` displays all allowed language tags (`Job`, `Task`, `Block`, `ACTION`, etc.) and automatically generates matching closing tags.
* **Attribute Completion:** Pressing space within a tag suggests all custom attributes relevant to that specific tag (`Name`, `Type`, `Rule`, etc.).
* **Hover Documentation:** Hovering over elements or browsing the completion list reveals hints and detailed explanations directly from the language specifications.

## Installation

1. Download the `magicdata-intellisense-X.X.X.vsix` installation file.
2. Open VS Code and navigate to the **Extensions** tab (`Ctrl+Shift+X`).
3. Click the three-dots menu icon (`...`) in the top-right corner.
4. Select **Install from VSIX...** and choose the downloaded file.

## Usage

Open any XML file or file with the `.magicdata` extension and start typing tags and attributes.
